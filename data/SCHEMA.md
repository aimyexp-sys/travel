# Dataset schema

Synthetic enterprise mobility trip-log dataset. Generated by `data-generator/generate_data.py`
with a fixed random seed (42) — re-running the script reproduces this exact dataset.
Covers weekdays only, 2026-06-01 to 2026-08-31 (66 weekdays).

All tables are plain CSV under `data/`. Primary keys are noted per table; foreign keys reference
the primary key of the named table.

## employees.csv
| column | type | notes |
|---|---|---|
| employee_id | string, PK | e.g. `E00001` |
| name | string | |
| department | string | one of Engineering / Operations / Customer Support / Finance / HR / Sales |
| shift_id | string, FK → shifts.shift_id | **nullable** — ~4% of rows have a null shift or zone, simulating an incomplete roster |
| pickup_zone | string | **nullable**, see above |

## shifts.csv
| column | type | notes |
|---|---|---|
| shift_id | string, PK | S1/S2/S3 |
| shift_name | string | Day Shift / General Shift / Night Shift |
| scheduled_start | string HH:MM | |
| scheduled_end | string HH:MM | |

## vendors.csv
| column | type | notes |
|---|---|---|
| vendor_id | string, PK | V1–V5 |
| vendor_name | string | Vendor A–E |
| mode_types_served | string | `\|`-delimited, e.g. `cab\|nodal` |
| contract_start | date | |

## drivers.csv
| column | type | notes |
|---|---|---|
| driver_id | string, PK | e.g. `D0007` |
| vendor_id | string, FK → vendors.vendor_id | |
| driver_name | string | |
| rating | float | 1–5 |

## routes.csv
| column | type | notes |
|---|---|---|
| route_id | string, PK | e.g. `R001` |
| mode | string | cab / nodal / shuttle |
| origin_zone | string | one of the 8 pickup zones |
| destination_zone | string | always `Office Campus` in this sample |
| planned_distance_km | float | |

## trips.csv
| column | type | notes |
|---|---|---|
| trip_id | string, PK | e.g. `T000123`. **Note:** ~0.5% of trip_ids appear twice (a deliberately injected duplicate-row data-quality issue — see ANSWER_KEY.md) |
| route_id | string, FK → routes.route_id | |
| driver_id | string, FK → drivers.driver_id | |
| vendor_id | string, FK → vendors.vendor_id | |
| shift_id | string, FK → shifts.shift_id | |
| scheduled_pickup_time | datetime ISO8601 | |
| actual_pickup_time | datetime ISO8601 | **nullable** — null on no-shows and a small % of unlogged events |
| scheduled_drop_time | datetime ISO8601 | |
| actual_drop_time | datetime ISO8601 | **nullable** — null unless status is `completed` |
| distance_km | float | |
| cost | float | total trip cost |
| mode | string | cab / nodal / shuttle |
| status | string | completed / no_show / cancelled |

## trip_employees.csv
Many-to-many: which employees rode which trip.

| column | type | notes |
|---|---|---|
| trip_id | string, FK → trips.trip_id | |
| employee_id | string | **~2.5% of rows reference an employee_id NOT present in employees.csv** — a deliberately injected roster-mismatch data-quality issue |

## gps_traces.csv
Sparse GPS pings per trip — **not every trip has traces** (deliberate gaps, see ANSWER_KEY.md).

| column | type | notes |
|---|---|---|
| trip_id | string, FK → trips.trip_id | |
| timestamp | datetime ISO8601 | |
| lat | float | |
| lon | float | |
| speed | float | km/h |

## delay_records.csv
One row per trip.

| column | type | notes |
|---|---|---|
| trip_id | string, FK → trips.trip_id | |
| delay_minutes | float | minutes late vs. scheduled pickup |
| delay_reason_code | string | **nullable** (null when delay ≤ 2 min); one of traffic / driver_late / vehicle_issue / route_change / unknown |

## safety_incidents.csv
Sparse — most trips have none.

| column | type | notes |
|---|---|---|
| incident_id | string, PK | |
| trip_id | string, FK → trips.trip_id | |
| incident_type | string | harsh_braking / speeding / near_miss / minor_collision |
| severity | string | low / medium / high |
